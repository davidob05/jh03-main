\section{Frontend component map}
\label{sec:frontend:components}

This section maps the main frontend pages and shared components. It is intended as a navigation aid for maintainers rather than exhaustive API documentation.

\subsection{Routing layout}
\label{subsec:frontend:components:routing}

Routing is defined in \texttt{src/Routes.tsx} and uses two layout shells:

\begin{itemize}
  \item \texttt{AdminLayout}: wraps all \texttt{/admin/*} routes.
  \item \texttt{InvigilatorLayout}: wraps all \texttt{/invigilator/*} routes.
\end{itemize}

\subsection{Admin dialogs and shared components}
\label{subsec:frontend:components:admindialogs}

Admin dialogs live in \texttt{src/components/admin}. Key components:

\begin{itemize}
  \item \texttt{UploadFile}: Excel ingestion UI.
  \item \texttt{AssignInvigilatorDialog}, \texttt{EditInvigilatorDialog}, \texttt{InvigilatorAvailabilityModal}: assignment and availability tooling.
  \item \texttt{DietManager}: diet administration UI.
  \item \texttt{NotificationsPanel}, \texttt{NotifyDialog}: admin messaging and mail merge.
  \item \texttt{ExportInvigilatorTimetablesDialog}, \texttt{ExportProgressDialog}: CSV export flows.
\end{itemize}

Shared cross-role components live in \texttt{src/components} (e.g., \texttt{RequireAuth}, \texttt{RequireRole}, \texttt{Panel}, \texttt{PillButton}).
